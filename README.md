# 🌐 Natural Park-Cyberdefense

Projeto técnico de segurança cibernética aplicado a um parque biológico de alta segurança, inspirado em zoológicos modernos — funcional, redundante e sem falhas.

Este repositório simula um ambiente crítico composto por três setores principais: **OT/ICS**, **SOC/DFIR** e **Laboratórios/Banco Genético**.  
O objetivo é demonstrar domínio técnico em defesa cibernética, investigação, resposta a incidentes e modelagem de ameaças.

---

## 🎯 Objetivo do Projeto

- Criar um ambiente crítico com múltiplos setores biológicos.
- Simular ataques, incidentes e respostas SOC/DFIR.
- Mapear técnicas MITRE ATT&CK.
- Demonstrar domínio em OT/ICS, Blue Team e DFIR.
- Produzir documentação profissional para portfólio.

---

## 📁 Estrutura do Repositório

- **docs/** → Threat Model e Relatório Final  
- **ambiente-1/** → OT/ICS  
- **ambiente-2/** → SOC + DFIR  
- **ambiente-3/** → Laboratórios + Banco Genético
