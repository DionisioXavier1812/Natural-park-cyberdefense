# Threat Model – Natural Park-Cyberdefense

Parque biológico com múltiplos setores críticos, incluindo felinos, serpentário, aquário, laboratórios avançados, banco genético e infraestrutura OT/ICS.

## 2. Ativos Críticos
- Banco Genético
- Laboratórios
- OT/ICS
- SOC
- Sensores IoT
- Controle ambiental
- Aquário oceânico

## 3. Ameaças
- Intrusão OT/ICS
- Sabotagem ambiental
- Exfiltração genética
- Comprometimento IoT
- Movimento lateral entre setores

## 4. Vetores de Ataque
- Credenciais roubadas
- Exploração de APIs IoT
- Vulnerabilidades OT
- Engenharia social

## 5. Controles
- MFA
- Segmentação total
- Monitoramento SOC
- Playbooks
- Hardening OT/ICS
